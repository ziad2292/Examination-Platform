## Remediation update

AUTH-01, SAVE-01, PERF-01 and SEO-01 are implemented with regression coverage. DEP-01 runtime advisories are cleared by compatible updates; eight moderate lint-tool dependency findings remain because the suggested automatic fix would downgrade the framework lint configuration. No forced downgrade or incompatible minimatch override was applied.

A11Y-01 is now confirmed for contrast. `evidence/accessibility-before.json` records 37 failing nodes across nine of ten sampled routes, with ratios down to 3.31 against the required 4.5 for small text. Muted color and the affected secondary text classes were darkened without changing the red theme or layout. Timer announcements and manual AT review remain open.

A11Y-02, Medium, is confirmed invalid teacher summary markup. Axe reports definition-list and dlitem errors because nested div/span children separated dt/dd from dl. The fix changes only grouping elements, keeping card layout and text. Verification is the rendered teacher-page axe scan, now clear. Readiness-aware scanning also checks the actual streamed content rather than only a temporary loading fallback.

The user explicitly chose to document SAVE-02 for a separate approved change. Submission behavior is unchanged. Treat it as a risk requiring controlled reproduction; Next's client action dispatcher serializes normal Server Actions, so a same-tab in-flight race is not established merely by reading the component. Offline replay and cross-device timing still require characterization.

November 10 update for OPS-01 and SCALE-01: all 22 application migrations replayed successfully in an isolated container, clean npm ci passed, and a portable browser CI job was added (hosted execution pending). SCALE-02 is a new measured High risk: database-only save p99 reached 9.69 seconds with 200 zero-think-time clients under a 2-CPU cap. All 8,050 transactions and 350 final-grade checks were correct. See the supplemental report before interpreting these results as application capacity. Shared local data was preserved and disposable resources were removed.
